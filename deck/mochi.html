なぜ つくったか

しんどいと、動きたくない。
楽しいと、気づいたら動いている。

しんどい→ 動きたくない
楽しい→ 気づいたら動いている

病室やプレイルームの夜。手をちょっと動かすだけで遊べるものを作りたかった。

見出しの言葉は、チームの理学療法士のコメントから。

  1. びょういんの よるは、ながいんだって。
  2. しんどいと、うごきたく なくなる。
  3. でも たのしいと、きづいたら うごいてる。
  4. だから、てを ちょっと うごかすだけで あそべる ものを つくったよ。

なぜ 明るさブロックなのか

ログを見ると、1秒に約20回。

4,111回の通知（204 秒）
約 50msごとに届く（平均）
26 → 671手なし（最も多い値）→ 近づけた
2,150組が、直前とまったく同じバイト列

公式ドキュメントの定時通知は「500 ms 毎」。実物では平均約 50 ms ごと（1 秒に約 20 回）に届き、チェックサムは 4,111 回すべて一致した。だから、近づけた長さと離す速さまで分かる。

  1. ぼくが いちばん すきなのは、あかるさの ブロック。
  2. ログを みたら、1びょうに 20かいも あいずが きてたんだ。
  3. だから、てを ちかづける ながさや、はなす はやさまで わかる。
  4. にぎらなくても、ふらなくても、てを かざすだけで あそべるよ。

なぜ 3 つのブロックなのか

動ける大きさに合わせて、選べる。

きほん

明るさ

かざす

いちばん小さな動き。もちを押す・飛ばす、ゲームで跳ぶ。

指 1 本

ボタン

おす

ロケットが、ゆっくり空へ上がる。

おまけ

動き

ふる

背景が月面・火星・木星・土星へ。ゲームでは星が落ちてくる。

点滴が入っていると、大きく振る動きは制限されることがある— チームの理学療法士のコメントの要約

  1. ブロックは 3つ つかうよ。
  2. かざす、おす、ふる。うごきの おおきさが ちがうんだ。
  3. てんてきが あると、おおきく ふるのは むずかしいって、りがくりょうほうしさんが おしえてくれた。
  4. だから きほんは、かざすだけの あかるさ。ふるのは おまけ だよ。

あそびかた

押す。飛ばす。跳ぶ。めぐる。

手の動きは 5 つ：ちょん短め長め握るじっと　点数とれんさはあるけど、負けはない。

  1. てを ちかづけると、ぼく つぶれるの。
  2. はなすと、ちいさな もちが とんで、えに のこる。
  3. 「あそぶ」を おすと、ほしを あつめる ゲーム。てんすうは あるけど、まけは ないよ。
  4. ふると、げつめんや どせいに いけるんだ。

チームの理学療法士に聞いたこと（要約）

現場の目で、見てもらった。

手の動き

点滴があると大きく振る動きは制限されることがある。感度を調整すれば、振るもできそう。

映す場所

天井だけでなく、カーテン（横の壁）に映せれば、横向きしかできない子も楽しめる。

一緒に

最初はリハビリや看護師と一緒に。親子でできれば、不安な親の心のケアにも。

清潔

抗菌や、アルコール綿で拭いて清潔を保てる素材の工夫を。

注意

熱中しすぎたり、競争が生まれる仕掛けは、体によくない。

確かめ方の案

活動量計での活動量、睡眠時間、手術後の子のせん妄の観察スケール。

いただいたコメントの要約。効果を確かめたものではない。

  1. チームの りがくりょうほうしさんに、きいて みたよ。
  2. よこむきしか できない こも いるから、カーテンに うつすのも いいって。
  3. でも、むちゅうに なりすぎたり、きょうそう したり するのは、からだに よくないって。
  4. ぼく、ちゃんと きいたよ。

いま、どこまで

確かめた

  • 明るさブロックを、Mac の Chrome で実物につないで動いた
  • 動きブロックの「振る」も、Mac で動いた
  • 204 秒の記録：通知 4,111 回、チェックサムはすべて一致
  • その記録から切り出した 10.4 秒ぶんを時刻どおりに流し直すテストを含む、自動テスト 64 件

まだ

  • ほかの人に遊んでもらったことはない
  • 子どもや病室で意味があるかは、確かめていない
  • 横の壁への投影・拭ける素材・振る感度・「やすもう」は、これから
  • 手の動きの境目は、開発中にとった手の記録から決めた
  1. しょうじきに いうね。
  2. あかるさと、ふる ブロックは、ほんものと つながったよ。
  3. でも、こどもや びょういんで いみが あるかは、まだ たしかめて ないんだ。

これから

聞いたことを、形にする。

  • 横の壁にもカーテンに映して、横向きでも遊べるように
  • やすもう遊びすぎたら、もちが声をかける。点数を出さない遊び方も
  • 感度小さく振っても反応するように、調整できるように
  • 清潔アルコール綿で拭けるカバー
  • 一緒に最初はリハビリの方・看護師さんと、親子で試す
  • 光と音花火のまぶしさや「ドーン」の音を、弱められるように
  1. つぎは、よこの かべにも うつりたいな。
  2. あそびすぎたら、やすもうね って ぼくが いうよ。
  3. さいしょは、おとなの ひとと いっしょに ためしたい。
